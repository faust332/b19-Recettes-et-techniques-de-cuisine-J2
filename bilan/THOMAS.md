# Bilan individuel - THOMAS

## Mon niveau de départ :
- Au début de l'atelier, j'avais déjà quelques connaissances en développement web, notamment en HTML, CSS et JavaScript, ainsi que des notions de base sur Git, mais je manquais encore de pratique pour comprendre le fonctionnement de JavaScript, utiliser les différentes commandes Git et travailler avec les tests automatisés.

## Compétences acquises :
- Au cours de l'atelier, j'ai appris à mieux comprendre l'organisation des
fonctions JavaScript et leur rôle dans le fonctionnement de l'application. J'ai notamment travaillé sur la gestion du comportement de l'application pour éviter qu'une interruption ou une erreur ne perturbe l'affichage de la page.

- J'ai appris à mieux utiliser Git dans le cadre d'un projet collaboratif, notamment en travaillant avec des branches. J'ai également découvert comment effectuer une pull request et fusionner une branche avec la branche principale. Cela m'a permis de mieux comprendre comment plusieurs développeurs peuvent travailler sur un même projet sans écraser leurs modifications et comment intégrer leur travail de manière organisée.

## Points à renforcer

- je dois encore pratiquer les différentes commandes, notamment la gestion des branches, des commits et des fusions, pour devenir plus autonome.
- Renforcer mes compétences dans JavaScript et les tests automatisés. Je souhaite mieux comprendre comment écrire des tests, interpréter les erreurs et corriger le code lorsqu'un test échoue.

## Prochain objectif

Devenir plus autonome dans l'utilisation de Git et dans le développement de JavaScript. Être capable de modifier ou d'ajouter une fonctionnalité, de vérifier son fonctionnement grâce aux tests automatisés, puis d'enregistrer et de partager mon travail avec Git sans avoir systématiquement besoin d'aide.
